# خطة تعديل موقع شركة شورى إخوان

> **الحالة: نُفِّذت كامل المراحل الخمس.** المتبقّي هو بيانات من الزبون فقط —
> راجع قسم [ما ينتظر الزبون](#ما-ينتظر-الزبون) في الأسفل.

## السياق

الموقع الحالي مبني على هوية **"مجموعة شركة شورى" — مياه ومسابح ومقاولات**. ملف الزبون
`FULL WEBSITE.txt` يصف شركة مختلفة تماماً: **"شركة شورى إخوان" — التوريدات الهندسية منذ 1978**
بخمسة قطاعات (مضخات، توليد، ضواغط، غازات طبية، عُدد صناعية) ووكالات عالمية.

الصفحة الرئيسية وحدها حُدّثت جزئياً. الباقي — الصفحات، الـ Seeders، القائمة، الفوتر،
بيانات SEO — ما زال على الهوية القديمة، وهناك سبع صفحات مطلوبة غير موجودة إطلاقاً.

**النتيجة المستهدفة:** موقع مطابق بالكامل لملف الزبون، بمحتوى حقيقي، وكل الأقسام
الجديدة قابلة للإدارة من لوحة التحكم دون مبرمج.

## القرارات المعتمدة

| # | القرار |
|---|--------|
| 1 | القطاعات + العلامات التجارية + الفروع → جداول DB مع CRUD كامل في `/admin` |
| 2 | حذف `/products` و `/companies` نهائياً (مع 301 redirects) |
| 3 | النماذج: حفظ في DB + صندوق وارد بلوحة الإدارة، ثم تحويل تلقائي لتطبيق البريد (`mailto`) معبّأً ببريد القسم والبيانات |
| 4 | الأصول من `docs/Website/` و `docs/مجلد جديد/` تُنقل إلى `public/images/` |

## المرحلة 1 — قاعدة البيانات

### جداول جديدة

| الجدول | الأعمدة الأساسية |
|--------|------------------|
| `sectors` | name, slug, tagline, intro(text), specialties(json), icon, image, order, is_active |
| `brands` | name, slug, country, description, logo, is_agency(bool), order, is_active |
| `brand_sector` | brand_id, sector_id (علامة واحدة قد تخدم عدة قطاعات — مثل ALUP) |
| `branches` | name, city, address, phone, mobile, description, map_top, map_left, map_embed, order, is_active |
| `wholesale_requests` | name, product_interest, governorate, address, message, is_read |
| `job_applications` | full_name, phone, email, department, preferred_branch, cover_letter, cv_path, is_read |

`specialties` عمود JSON على نمط `services.features` الموجود — يُحرَّر في اللوحة
كسطر لكل بند، أبسط بكثير من جدول منفصل.

### مفاتيح `settings` جديدة

`about_subtitle` · `sectors_intro` · `services_intro` · `brands_intro` ·
`projects_intro` · `wholesale_intro` · `careers_intro` · `contact_intro` ·
`contact_email` · `sales_email` · `hr_email` · `wholesale_whatsapp` · `working_hours`

### Seeders مُعاد كتابتها بالكامل من ملف الزبون

- **`TimelineNodesSeeder`** → 1978 / 1995 / 2002 / 2005 / 2008 / 2010 / 2025 بالنصوص الحرفية
- **`ServicesSeeder`** → الخدمات الأربع (استشارات ومناقصات · تسليم مفتاح · صيانة وما بعد البيع · توزيع وصالات عرض)
- **`SectorsSeeder`** (جديد) → القطاعات الخمسة بنبذاتها وتخصصاتها
- **`BrandsSeeder`** (جديد) → العلامات + الوكالات الستّ الرسمية مع ربطها بالقطاعات
- **`BranchesSeeder`** (جديد) → المرجة / البرامكة / حلب بالأرقام الحقيقية من الملف
- **`ProjectsSeeder`** → مشروع أوكسفام 80 KVA
- **`NewsSeeder`** → خبر EMS PUMP بالنص الكامل
- **`CategoriesSeeder`** → تصنيفات مشاريع وأخبار مطابقة للقطاعات
- **`ClientsSeeder`** → Oxfam · السورية للاتصالات · السورية للبترول · مؤسسة الكهرباء · مؤسسة المياه · الصندوق السيادي
- **`SettingsSeeder`** → نصوص "من نحن" الثلاث والرؤية والرسالة حرفياً من الملف

## المرحلة 3 — الصفحات العامة

### الرئيسية `welcome.blade.php`
ترتيب الأقسام حسب الملف: هيرو → من نحن → الرؤية والرسالة → **قطاعاتنا** (دائرة
"منذ عام 1978" في المنتصف وحولها بطاقات القطاعات الستّ مع "تطوير عقاري — قريباً") →
الخدمات والحلول → **شركاؤنا (قسم جديد)** → عملاؤنا → فروع صالاتنا → الأخبار.

يُحذف قسم "شركاتنا" (الكاروسيل في السطور 201-273) لأنه تكرار للقطاعات.

### صفحات جديدة
- **`about.blade.php`** — من `story.blade.php` مع الخط الزمني الجديد ونصوص الملف
- **`sectors/index.blade.php`** — شبكة البطاقات الخمس + النص الترحيبي
- **`sectors/show.blade.php`** — نبذة + التخصصات والمعدات + العلامات التجارية للقطاع
- **`brands.blade.php`** — الوكالات الستّ الرسمية كبطاقات + شبكة كل العلامات
- **`wholesale.blade.php`** — الترويسة + "لماذا الشراكة معنا" (4 نقاط) + النموذج
- **`careers.blade.php`** — الترويسة + بيئة العمل (3 نقاط) + النموذج مع رفع CV

### صفحات مُعاد كتابتها
- **`services.blade.php`** — الخدمات الأربع بنصوص الملف
- **`projects.blade.php`** — بطاقات تفصيلية (الجهة المستفيدة · القطاع · الوصف)
- **`contact.blade.php`** — بطاقات الفروع الثلاث بالأرقام الحقيقية + أوقات الدوام +
  النموذج + خريطة تفاعلية للمواقع الثلاثة

### النماذج
كلها تتبع نمط `handleContactSubmit` الموجود في `contact.blade.php:239-313`:
POST إلى Laravel → حفظ في DB → عند `ok` تفتح `mailto:` معبّأً ببريد القسم والبيانات.

**ملاحظة على نموذج التوظيف:** بروتوكول `mailto` لا يدعم إرفاق ملفات. الـ CV يُرفع
ويُحفظ في `storage/app/public/uploads/cvs`، ويُدرَج **رابط تحميله** داخل نص البريد،
والملف نفسه متاح للتحميل من صندوق الوارد في لوحة الإدارة.

## التحقق

```bash
php artisan migrate:fresh --seed     # يجب أن تمر كل الـ seeders دون أخطاء
npm run build
php artisan serve
```

قائمة الفحص:
1. كل رابط في القائمة والفوتر يفتح صفحة صحيحة — لا 404
2. `/products` و `/companies` و `/story` و `/branches` تُحوّل 301 للمسارات الجديدة
3. صفحات القطاعات الخمس تعرض التخصصات والعلامات المرتبطة بها
4. الشعارات الثمانية الناقصة تظهر كبطاقات نصية لا كصور مكسورة
5. النماذج الثلاثة: الطلب يُحفظ في DB ويظهر في `/admin`، ويُفتح تطبيق البريد معبّأً
6. رفع CV بصيغة PDF يعمل، والملف يُحمّل من لوحة الإدارة
7. الموقع سليم على الجوال (RTL) — القائمة، الشبكات، النماذج
8. لا يبقى أي ذكر لـ "المسابح" أو "المقاولات" في المشروع:
   `grep -ri "مسابح\|مقاولات" resources/ database/`

## ما ينتظر الزبون

هذه القيم موضوعة كـ placeholders في الكود، وكلها قابلة للتعديل من
**لوحة الإدارة ← النصوص والفقرات** دون مبرمج:

| البند | القيمة الحالية | ملاحظة |
|---|---|---|
| البريد الرسمي | `info@shorabrothers.com` | مثال ورد في ملف الزبون — يحتاج تأكيداً |
| بريد المبيعات | `sales@shorabrothers.com` | تُوجَّه إليه طلبات الجملة |
| بريد الموارد البشرية | `hr@shorabrothers.com` | تُوجَّه إليه طلبات التوظيف |
| واتساب الجملة | `963932101176` | مبني على جوال فرع المرجة |
| هاتف فرع البرامكة | `011 9870` | ورد في الملف بأربع خانات فقط |
| النطاق في `sitemap.xml` و `robots.txt` | `shora-group.sy` | يُستبدل بالنطاق النهائي قبل النشر |

**شعارات ناقصة (8):** BBC · PANELLI · KEYANG · DAB · Worthington · SICC · PENTAX · EMS PUMP.
تُعرض حالياً كبطاقات نصية. لإضافة أي شعار: ارفعه من **لوحة الإدارة ← العلامات التجارية ← تعديل**.

**صور ناقصة:** صورة مشروع أوكسفام وصورة خبر EMS PUMP — تُرفع من
**معرض المشاريع** و **المركز الإعلامي**.

## إصلاحات جانبية اقتضاها العمل

- **`bootstrap/app.php`** كان يمنع ردود JSON خارج `api/*`، فكانت أخطاء التحقق ترجع
  تحويلة HTML ولا يعرف الزائر أي حقل أخطأ فيه. الآن ترجع 422 مع رسالة عربية.
- **`HomeContentController`** كان يحفظ الإعدادات دون مسح كاش `setting()`
  (وهو `rememberForever`)، فلم تكن تعديلات الزبون تظهر في الموقع إطلاقاً.
- **`lang/ar/validation.php`** (جديد) — رسائل التحقق كانت تظهر بالإنجليزية.
- **`clients.logo`** صار يقبل `null` ليُعرض العميل كبطاقة نصية قبل توفر شعاره.
